🛡️ ReturnRadar — Privacy Policy

Last updated: May 2026

What This Extension Does

ReturnRadar is a browser extension that displays return policy information (Returnable, Replacement, Non-Returnable) on Amazon product search results. It helps shoppers make informed purchase decisions without clicking into every product page.

Data We Collect

We do NOT collect any personal information.

The extension processes the following non-personal data:

  • Amazon Product IDs (ASINs) — Used solely to look up and cache return policy status for products you view.
  • Return Policy Text — Extracted from Amazon product pages to determine returnability.
  • User Preferences — Your extension settings (e.g., tooltip toggle, filter preferences) stored locally on your device.

Data Storage

All data is stored locally on your device using the browser's built-in chrome.storage.local API. Cached product data automatically expires after 24 hours.

If the optional cloud cache feature is enabled, anonymised product return policy data (ASIN + return status only) may be stored on our Supabase servers to speed up lookups for all users. No personal data, browsing history, or account information is ever transmitted.

Network Requests

The extension makes the following network requests:

  • Amazon product pages (same-origin) — To fetch return policy information for products visible in your search results.
  • Supabase API (optional) — To read/write anonymised product return policy cache data. This can be disabled in settings.

No data is sent to any analytics, advertising, or tracking services.

Permissions Explained

  • storage — Saves cached return policies and your preference settings locally.
  • host_permissions (amazon.*) — Allows the extension to read Amazon product pages to extract return policy information. This is the core functionality of the extension.

Third-Party Services

The extension does not use any third-party analytics, advertising, or tracking services. The optional cloud cache uses Supabase for anonymous product data storage only.

Your Rights

  • You can disable the extension at any time from Chrome's extension manager.
  • You can clear all cached data by removing the extension.
  • You can disable cloud cache sync in the extension settings.

Contact

If you have questions about this privacy policy, please contact us through the Chrome Web Store support page for this extension.
